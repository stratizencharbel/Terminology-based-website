World Wide Web

The World Wide Web is a system of interlinked documents and resources that are accessed over the internet using web browsers.

The WWW is not the same as the internet — it is a service that runs on top of the internet. It was created by Tim Berners-Lee in 1989. The web allows users to access websites that are connected through hyperlinks. These websites are written mainly in HTML and are accessed using protocols like HTTP.

When you open a browser and type a website address, you are using the World Wide Web to retrieve and display information stored on web servers across the globe.
