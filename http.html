Hypertext Transfer Protocol

HTTP is a protocol used for transferring web pages and data over the internet.

HTTP defines how messages are sent between clients (browsers) and servers. It is a stateless protocol, meaning each request is independent.A more secure version, HTTPS, encrypts the data using SSL/TLS.

Key ideas:

  • Communication protocol
  • Request-response model
  • Stateless
