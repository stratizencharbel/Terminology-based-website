File Transfer Control

FTP is a protocol used to transfer files between computers over a network.

It allows users to upload and download files to and from servers. It usually requires authentication (username and password).

Modern alternatives include secure versions like SFTP.

Key ideas

  • File transfer system
  • Client-server model
  • Requires credentials
