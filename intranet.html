Hypertext Transfer Protocol

An intranet is a private network accessible only within an organization.

It uses internet technologies (like browsers and HTTP) but is restricted to internal users. It is commonly used for communication, file sharing, and internal systems.

Key ideas

  • Private and secure
  • Internal communication
  • Controlled access
