Domain Name System

DNS is a system that translates human-readable domain names into IP addresses.

Computers communicate using IP addresses (e.g., 192.168.1.1), but humans prefer names like google.com. DNS acts like a translator or phonebook, converting domain names into IP addresses so browsers can locate servers.

Without DNS, users would need to remember numeric IP addresses.

Key Ideas

  • Converts names to IP addresses
  • Essential for web navigation
